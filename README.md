# Hotel-Reservation-System
This hotel reservation system enables you to book and cancel rooms, which gives better conversation (user friendly) along with showing available rooms which helps users to book their desired rooms with types such as Standard, Deluxe and Suite rooms. This will be a better option for beginners with java and OOPs concept.

Hotel Reservation System

A simple console-based Hotel Reservation System developed in Java using Object-Oriented Programming (OOP) concepts.


This project allows users to:

View available rooms
Book rooms
Cancel reservations
Simulate payment processing
Features
Standard, Deluxe, and Suite room categories
Room booking system
Reservation cancellation
Payment simulation
Pre-booked rooms support for real world hotel reservation experience 
OOP-based design using classes and objects
Simple menu-driven interface


Technologies Used
Java
OOP Concepts
Arrays
Scanner Class
OOP Concepts Used
Classes and Objects
Room class represents individual rooms
Hotel class manages hotel operations
Encapsulation

Room data and hotel operations are organized inside classes.

Abstraction

Methods like:

displayRooms()
bookRoom()
cancelRoom()

hide internal implementation from the user.

Reusability

The same methods work for all room types.

Room Categories
Room Type	Room Numbers
Standard	101 - 130
Deluxe	201 - 230
Suite	301 - 330


Functionalities
Display Available Rooms

Shows only rooms that are currently available.

Booked rooms can be cancelled and made available again.
